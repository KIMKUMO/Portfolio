# Portfolio

게임 기획자 김재원의 이력서, 프로젝트 경험, 포트폴리오와 취미를 소개하는 반응형 랜딩 페이지입니다.

## 내용 수정하기

공개 페이지 오른쪽 아래의 **사이트 편집** 버튼을 누르면 브라우저에서 이력서 내용을 바로 수정할 수 있습니다.

- 이름, 직무, 연락처와 병역 정보 수정
- 경력·자격증·기술 항목 여러 개 추가
- 각 항목 순서 변경 및 삭제
- 브라우저 자동 저장
- 수정한 `content.js` 파일 내보내기와 다시 불러오기

브라우저 자동 저장은 현재 기기에만 적용됩니다. 모든 방문자에게 공개하려면 편집 패널에서 `content.js`를 내려받고 저장소의 기존 파일을 교체해 주세요. `main` 브랜치에 저장하면 페이지가 자동으로 다시 배포됩니다.

코드로 수정할 때도 대부분의 문구와 항목은 `content.js` 한 파일에서 변경할 수 있습니다.

- 이름과 연락처: `resume`
- 경력·자격증·기술: `resume.groups`
- 프로젝트 경험: `projects.items`
- 포트폴리오: `portfolio.items`
- 취미와 게임 장르: `hobbies`

이미지는 `assets` 폴더에 넣고 `content.js`에서 `assets/파일명` 형식으로 연결하세요. 수정 결과는 `index.html`을 브라우저에서 열어 바로 확인할 수 있습니다.

## 공개 페이지

`main` 브랜치에 변경 사항이 올라오면 GitHub Pages 배포 작업이 자동으로 실행됩니다.
